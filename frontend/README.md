# frontend

React-приложение (Vite) для проекта **aerocast** — карта химического состава воздуха и прогноз на 3 дня.

Полная инструкция по установке и запуску — в корневом [README](../README.md).

## Команды

```bash
npm run dev      # режим разработки (http://localhost:5173)
npm run build    # production-сборка
npm run preview  # предпросмотр production-сборки
npm run lint     # проверка ESLint
npm test         # прогон тестов (Vitest)
npm run test:watch  # тесты в режиме watch
```
